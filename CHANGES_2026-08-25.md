# Các thay đổi ngày 2026-08-25

Tài liệu này ghi lại các thay đổi được thực hiện sau khi đồng bộ nhánh `main` với `origin/main`.

## 1. Ổn định quá trình build Docker

- Thêm `--retries 5` và `--timeout 120` cho bước cài Python dependency.
- Giảm khả năng Docker build thất bại khi kết nối tới package registry chậm hoặc chập chờn.
- File: `Dockerfile`.

## 2. Sửa dependency resolution của frontend admin

- Source dùng chung nằm tại `Frontend/src`, bên ngoài root của app admin.
- Thêm Vite alias để các dependency dùng chung được resolve từ `Frontend/admin/node_modules`.
- Các package được định tuyến gồm Bootstrap, Bootstrap Icons, Framer Motion, React Hook Form và React Router DOM.
- Khắc phục lỗi build/runtime dạng `Rollup failed to resolve import`.
- File: `Frontend/admin/vite.config.js`.

## 3. Cải thiện trải nghiệm chat với Orbit

- Textarea tự tăng và giảm chiều cao theo nội dung, tối đa khoảng năm dòng.
- Khắc phục hiện tượng dòng đầu bị che và scrollbar native xuất hiện ngay khi xuống dòng.
- `Enter` để gửi, `Shift + Enter` để xuống dòng; không gửi nhầm khi đang dùng bộ gõ IME.
- Tự động cuộn mượt tới tin nhắn mới, trạng thái xử lý và phản hồi của Orbit.
- Tin nhắn được thêm lạc quan vào UI ngay khi gửi.
- Thêm animation cho message bubble và trạng thái `Orbit đang suy nghĩ`.
- Làm lại composer, nút gửi, trạng thái focus/disabled và giao diện responsive trên mobile.
- Files:
  - `Frontend/src/components/ai/PersonalAIChat.jsx`
  - `Frontend/src/assistant.css`

## 4. Không cho cấu hình AI cũ ghi đè khi thiếu credential

- Backend có thể tải provider/model từng được admin lưu trong bảng `system_config`.
- Trước đây, cấu hình OpenAI cũ vẫn ghi đè provider trong `.env` dù môi trường hiện tại không có OpenAI credential.
- Backend giờ chỉ khôi phục provider đã lưu khi credential tương ứng đang được cấu hình.
- Nếu credential không tồn tại, backend giữ provider/model từ `.env` và ghi warning an toàn, không ghi API key vào log.
- Trong môi trường local hiện tại, backend tiếp tục dùng Groq với model `openai/gpt-oss-20b`; tiền tố `openai/` là tên model trên Groq, không phải OpenAI API.
- File: `src/services/ai_config_service.py`.

## 5. Test hồi quy

- Thêm test xác nhận cấu hình provider đã lưu bị bỏ qua nếu môi trường thiếu credential tương ứng.
- Kết quả test service cấu hình AI: `7 passed`.
- Frontend user và admin đều build thành công.
- Backend Docker khởi động healthy và endpoint `/health` trả HTTP 200.
- File: `tests/test_services/test_ai_config_service.py`.

## Lưu ý vận hành local

- `.env` không được thêm vào commit và không có secret nào được ghi trong tài liệu này.
- Trong phiên chạy local, backend dùng cổng `8002` vì cổng `8000` đang được một project khác sử dụng; đây là cấu hình chạy tạm, không thay đổi `docker-compose.yml`.
